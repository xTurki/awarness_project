{# A module's cover: a repeating geometric pattern in a chosen colour. Four of the six are drawn from the Najdi vocabulary, as a geometric reading of it rather than a reproduction of any particular historical work: the stepped merlons that crown a mud-brick wall, the pierced triangular openings set into one, the arcade that carries it, and the running zigzag frieze. Drawn here rather than uploaded, which is why this needs no file storage and no image route. An SVG `pattern` tiles itself, so one small tile definition fills any size of banner and stays crisp at any zoom. The pattern and colour come from `module.art` through `app/art.py`. A module with nothing chosen still gets a cover, derived from its id, so the column was added to a live database without backfilling a single row. `currentColor` is used throughout, so the colour class on the wrapper drives the strokes and each pattern follows the light and dark themes.
